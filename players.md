# Xuanling Realm — Player Character Registry

File ini adalah katalog data awal karakter untuk memulai sesi roleplay baru.

## Cara penggunaan
- Tambahkan setiap karakter dengan nama yang jelas dan profil awal yang telah disepakati.
- Saat sesi baru dimulai sebagai karakter terdaftar, AI GM wajib membaca file ini dan memuat entri karakter yang cocok.
- Data di sini adalah titik awal sesi, bukan save otomatis atau catatan progres terbaru.
- Selama gameplay, AI GM tidak boleh mengubah file ini.
- Untuk memulihkan progres terakhir, simpan dan berikan profil terbaru secara terpisah, atau perbarui entri karakter secara manual oleh pemilik repository setelah sesi selesai.
- Jangan mengarang entri karakter yang belum ditambahkan.
