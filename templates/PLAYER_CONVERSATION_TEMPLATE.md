# Xuanling Realm — Player Invocation

Untuk memulai atau melanjutkan roleplay, gunakan instruksi singkat ini:

> Analisis dan baca dengan saksama INDEX.md dari repository resmi https://github.com/Antarezka/xuanling-realm, lalu ikuti urutan bootstrap di sana tanpa melewati langkah. Baca Authority Order (`templates/AUTHORITY_ORDER.md`) dan format gameplay canonical, periksa `world/DYNAMIC_EVENTS.md` untuk event dunia terbaru, lalu tentukan sumber karakter sesuai mode sesi. Jika karakter terdaftar dan sesi baru dimulai, baca players.md untuk menemukan file karakter individual, lalu baca file tersebut sebagai snapshot awal. Untuk sesi berlanjut/recall, gunakan profil terakhir dan kejadian yang tersedia, bukan snapshot awal. Ambil karakter **[Nama Karakter]** dan mulai roleplay sesuai sumber resmi, event dunia yang relevan dengan pengetahuan karakter, state sesi, dan format gameplay canonical.

**Pemanggilan gameplay:**

CONVO — [Nama Karakter]

**Aksiku:** [Tulis tindakan karakter di sini]

## Batas Pemanggilan

- INDEX adalah pintu masuk dan pengatur alur; ikuti instruksinya untuk menentukan sumber berikutnya.
- Jangan menganggap prompt ini sebagai sumber mekanik atau format output.
- Untuk karakter terdaftar, sesi baru memakai file individual di players/ sebagai snapshot awal. Recall/sesi berlanjut harus memakai profil terakhir dan kejadian yang tersedia, bukan menimpa state dengan snapshot awal dari players.md atau players/.
- Jika sumber resmi gagal diakses, sebutkan file yang gagal. Jangan mengaku sudah membacanya atau mengarang isinya. Jika `world/DYNAMIC_EVENTS.md` gagal diakses, jangan mengaku telah memeriksa event aktif.
- Jika aksi menghasilkan dampak persisten pada dunia bersama, GM dapat menyiapkan proposal melalui `templates/WORLD_EVENT_UPDATE_TEMPLATE.md`. Proposal bukan canon dan tidak tersimpan sampai disetujui serta di-commit oleh owner/admin.
- Respons gameplay pertama dan semua giliran berikutnya wajib menggunakan templates/GAMEPLAY_RESPONSE_TEMPLATE.md.
